WLOC 模块安装教程

按顺序完成模块订阅、CA 证书信任与 HTTPS 解密，再用选点网页写入坐标并验证定位。

开始第一步 打开 GitHub

流程概览

① 安装模块 复制订阅地址并在 Shadowrocket 模块中下载 ② 信任证书 安装 CA 并在系统证书信任设置中开启 ③ HTTPS 解密 开启解密并重启一次代理 ④ 选点测试 写入坐标、切换定位开关后在地图确认

1

安装模块

从 GitHub 获取 Shadowrocket 模块订阅地址，并在 App 中下载安装。

  1. 打开 GitHub 仓库页面，下滑找到 Shadowrocket 订阅地址，复制。

    仓库 https://github.com/Yu9191/wloc
    打开
    模块 https://raw.githubusercontent.com/Yu9191/wloc/refs/heads/main/modules/wloc.module
    打开

  2. 打开 Shadowrocket，按下列路径进入模块页：

    底栏「配置」 「模块」

  3. 点右上角 + → 粘贴订阅地址 → 点 下载 → 成功。

    模块列表中出现对应条目，即表示第一步完成。
2

安装并信任 CA 证书

在 Shadowrocket 安装证书后，还需在 iOS 系统设置中完成描述文件安装与完全信任。

  1. 进入配置编辑：

    底栏「配置」 本地文件 「编辑配置」

  2. 点 HTTPS 解密 → 点 证书，检查是否被系统信任。

    默认通常显示「未被系统信任」。

  3. 点 安装证书 → 点 允许。

  4. 到系统设置安装描述文件：

    设置 已下载描述文件 安装

    按提示输入锁屏密码，再连续确认「安装」直至完成。

  5. 开启证书完全信任：

    设置 关于本机 证书信任设置

    拉到最底部，打开刚安装证书的信任开关。

    仅完成「描述文件安装」不够，必须在「证书信任设置」中打开开关，HTTPS 解密才会生效。
3

开启「HTTPS 解密」

确认证书已受信任后开启解密，并重启一次代理使配置生效。

  1. 回到 Shadowrocket，证书应显示 系统已信任 → 点右上角对勾保存。

  2. 打开 HTTPS 解密 开关 → 再点右上角对勾 → 成功。

  3. 点底栏 首页，在顶部关闭再开启一次代理。

    重启代理有助于让新模块与解密配置立即生效。
4

测试选点定位

在选点网页写入坐标到模块，通过开关定位服务验证地图 App 是否生效。

选点站 https://lbs.lolnb.com/
打开

  1. 打开选点网页 → 底部搜索「行政区地名」→ 点 储存到设备。

    出现绿色「已储存」、且无红色报错，说明坐标已写入模块。

  2. 临时关闭系统定位：

    设置 隐私与安全性 定位服务 关闭开关

  3. 回到 Shadowrocket，关闭再开启一次代理。

  4. 等待几秒，再打开定位开关。

  5. 打开任意地图 App，确认定位点是否已切换到所选位置。

    若未生效：确认模块已下载、证书已信任、HTTPS 解密已开，并再次重启代理后重试。

全部步骤完成后即可使用

日常使用：选点站写入新坐标 → 开关一次系统定位 → 刷新地图即可。
